Place the official "Get it on Google Play" badge here as `google-play.png`, `google-play.webp` or `google-play.svg`
(download from https://play.google.com/intl/en_us/badges/). It is shown only when `googlePlayUrl` in
`src/config/site.ts` is set. Without the file, a plain text button is shown instead; the badge is never redrawn.
